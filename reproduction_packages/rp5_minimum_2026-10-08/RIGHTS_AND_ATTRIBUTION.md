bootstrap reference includes uncertified p/q fields and must not be described
as accepted writer-aware inference.

own terms. Exact local resource hashes are recorded in
[inputs_contract.json](inputs_contract.json); hashes do not grant access or
redistribution permission. Fine-tuned grammar weights are a project artifact,
not interchangeable with a generic roberta-base download. Resource acquisition
and parser-path configuration remain prerequisite steps; nothing is downloaded
automatically by the package verifier.

Provider IDs and unexpanded prompt templates record the experiment's
configuration. No immutable historical provider snapshot, present-day service
availability or retrospective provider permission is asserted. The package
contains no paid-generation client and no API token. Reproduction starts from
existing, legitimately held synthetic texts; fresh generation is a new run.

Neither manuscript nor supplementary PDF/TeX, figure artwork or review records
belong to this package. Earlier local PDF packages are historical review
artifacts and are not part of this proposed repository delivery.
